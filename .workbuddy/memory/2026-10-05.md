### 坑与教训（可复用）

1. **vite.config.js 块注释里写了 `playgrounds/*/`，`*/` 把块注释提前终止** → 构建报语法错误且提示晦涩。注释里别出现 `*/` 字样。
2. **experience-cli.js lintExports 残留 `path.join(__dirname, 'src', 'lib', 'registry.json')`** ——kits 搬迁时的漏网之鱼（`'src','lib'` 是 join 分参，grep 'src/lib' 抓不到），导致「导出物过期」检查静默失效（registry mtime 被当 0，只比对经验文件）。已修 `../kits/registry.json`。
   → **教训：目录搬迁后扫残留要覆盖多种写法**（join 分参、`new URL(...)` 字符串、import.meta 派生），并对 storeDir / REGISTRY_URL 这类派生路径直接打印实证，别只信 grep 干净。
3. **`__dirname` / `import.meta.url` 深了一层，向外路径全要加 `..`**：experience.js 存储目录、lib-registry 的 `../kits/registry.json`、server.js 的 `../dist` 与 `../package.json`（引入 ROOT_DIR 收口）、expert-export 的 `../package.json`、experience-cli 的 SKILL_OUT。六文件之间同目录相对导入不用动。
4. **server.js stdin 关闭即触发 MCP 优雅退出**（协议行为）。脱离 MCP 客户端长跑调试：`sleep 600 | node scripts/server.js` 保住 stdin。
